# Project Twilight

This is the **Twilight** data-collection app (the current replacement for Orbit).

## Open the app

After this version is published to the live site, open:

**https://dk-centific.github.io/Orbit-Tracker/**

You should see a login screen titled **Project Twilight**.

If a bookmark still says Orbit, it is usually the old published copy. Use the link above, then refresh the page (on a computer: Ctrl+Shift+R / Cmd+Shift+R). Old Orbit filenames such as `orbit.html` now send you to Twilight.

Login IDs (for example `Admin-orbit`) and Excel column names stay the same. Only the name you see on screen is Twilight.

## Files that make up the app

- `index.html` — the Twilight home / login page
- `twilight.js` — the Twilight app
- `twilight-panic.js` — Help & safety
- `orbit.html` — old Orbit address; redirects to Twilight
